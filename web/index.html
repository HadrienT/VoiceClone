Live / Discord

Parlez dans votre micro, la voix clonée sort en direct sur un câble audio virtuel que Discord utilise comme micro. Le calcul se fait sur le serveur (GPU).

🎬 Intégrations : OBS, Twitch, bot Discord

Sous-titres et indicateur de parole dans OBS : ajoutez une Source navigateur avec cette adresse (fond transparent, se met à jour seule pendant le Live) :

Ouvrir

Options à ajouter à l'adresse : &size=48 (taille), &lines=1, &show=subs ou indicator, &position=top, &translation=only, &fade=0 (garder affiché), &key=MOTDEPASSE si l'interface est protégée.

Lire le chat Twitch avec votre voix clonée pendant le Live :

python integrations/twitch_tts.py --channel VOTRE_CHAINE --command "!tts" --cooldown 20

Bot Discord (file d'attente, une voix par membre, lecture d'un salon textuel) : python discord_bot/bot.py — voir le README.

💬 Dire dans le Live (avec la voix clonée, mêlé au flux envoyé à Discord)

🎮 Brancher sur Discord

  1. Installez un câble audio virtuel :
    • Windows : VB-CABLE (gratuit)
    • macOS : BlackHole 2ch
    • Linux : ./scripts/linux_virtual_mic.sh (PulseAudio / PipeWire)
  2. Ici, gardez « Audio de ce PC », choisissez votre vrai micro en entrée et le câble en sortie (CABLE Input, BlackHole 2ch ou VoiceClone_Sink). Les câbles détectés sont marqués ★. Mettez votre casque en « Retour casque » pour vous entendre. Utilisez Chrome ou Edge.
  3. Dans Discord → Paramètres → Voix et vidéo : périphérique d'entrée = CABLE Output / BlackHole 2ch / VoiceClone_Mic.
  4. Dans Discord, désactivez la suppression de bruit (Krisp) et la sensibilité automatique, sinon la voix générée peut être coupée.
  5. Commencez par le mode « Test du routage » pour vérifier que Discord vous entend.

Astuce : OpenVoice V2 est le plus rapide pour le direct. Sur GPU, Chatterbox VC donne un timbre plus fidèle. Le mode « Transcription + TTS » ajoute ~1-2 s mais la voix est 100 % celle du clone. Un bot Discord pour lire du texte est aussi fourni dans discord_bot/.

Entraînement

Pour aller plus loin que le clonage instantané : un modèle appris sur votre voix. Demande un GPU, plusieurs minutes de voix propre et du temps (de 20 min à quelques heures). Tout se passe en arrière-plan.

🗣️ Affiner XTTS v2 sur cette voix

Le modèle obtenu apparaît dans la liste des modèles (« XTTS · votre voix ») : timbre et accent plus fidèles qu'en zero-shot. Idéal : 5 à 30 min d'audio transcrit.
